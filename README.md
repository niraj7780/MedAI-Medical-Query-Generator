🩺 MedAI — Medical Query Generator

🤖 AI-powered medical information assistant built with Python, Flask, and Google Gemini.

MedAI is a web application that lets users ask medical and health-related questions and receive clear, structured, educational responses generated by Google's Gemini AI.

⚠️ Important: MedAI is an educational project. It does not diagnose medical conditions, prescribe medication, or replace a qualified healthcare professional.

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/niraj7780/MedAI-Medical-Query-Generator.git
cd MedAI-Medical-Query-Generator

2. Create a Virtual Environment

Windows PowerShell

python -m venv venv

Activate it:

.\venv\Scripts\Activate.ps1

If PowerShell blocks activation:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Then activate the environment:

.\venv\Scripts\Activate.ps1

3. Install Dependencies

Install the required packages:

pip install -r requirements.txt

Or install them manually:

pip install flask python-dotenv google-genai

🔑 Gemini API Setup

MedAI uses Google's Gemini API to generate responses.

Get a Gemini API Key

Open Google AI Studio:

https://aistudio.google.com/apikey

Create an API key and copy it.

Create .env

Create a file named .env in the project root:

MedAI-Medical-Query-Generator/
│
├── .env
├── app.py
├── README.md
└── ...

Add:

GEMINI_API_KEY=YOUR_GEMINI_API_KEY

Example:

GEMINI_API_KEY=your_api_key_here

🔐 Never publish your real API key on GitHub.

🔐 Environment Security

Your .env file should be ignored by Git.

Your .gitignore should contain:

venv/
.env
__pycache__/
*.pyc

Check your Git status before pushing:

git status

If .env appears under files to be committed, stop and remove it from Git tracking before pushing.

▶️ Run the Application

Start the Flask server:

python app.py

You should see something similar to:

* Running on http://127.0.0.1:5000

Open your browser and visit:

http://127.0.0.1:5000

💬 How to Use

Step 1 — Open MedAI

Open:

http://127.0.0.1:5000

Step 2 — Enter a Question

Type a medical question into the input box.

Example:

What are common symptoms of dehydration?

Step 3 — Generate a Response

Click the Generate Response button.

Step 4 — Read the Result

MedAI sends the question to Gemini and displays the generated educational response.

You can also:

📋 Copy the response

🗑️ Clear the response

🌙 Switch between light and dark mode

🔄 Ask another question

💡 Example Questions

Try questions such as:

What are common symptoms of dehydration?

What causes a common cold?

What can cause a headache?

What are common symptoms of seasonal allergies?

What are some common causes of fatigue?

🔌 API Endpoint

MedAI uses a Flask endpoint to process medical questions.

POST /ask

Request

{
  "query": "What are common symptoms of dehydration?"
}

Response

{
  "response": "AI-generated medical information..."
}

Empty Query

If no question is provided:

{
  "error": "Medical question cannot be empty."
}

🧠 AI Safety

MedAI is designed to provide general educational information rather than medical diagnosis or treatment.

The AI instructions encourage the assistant to:

Provide general educational information

Avoid claiming to diagnose users

Explain possible causes when appropriate

Explain common symptoms

Provide general health guidance

Recommend professional medical care when appropriate

Highlight potential emergency situations

Avoid personalized medication prescriptions or dosages

Encourage users to consult qualified healthcare professionals

⚠️ Medical Disclaimer

MedAI is an educational AI project.

It should not be used as a substitute for professional medical advice, diagnosis, or treatment.

MedAI does not:

❌ Diagnose diseases

❌ Replace doctors

❌ Prescribe medication

❌ Provide personalized treatment

❌ Replace emergency medical services

AI-generated information can be incomplete, inaccurate, or unsuitable for a particular person.

For personal medical concerns, consult a qualified healthcare professional.

🚨 If you believe you are experiencing a medical emergency, seek appropriate emergency medical care immediately.
